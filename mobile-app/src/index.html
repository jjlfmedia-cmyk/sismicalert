Que Hacer

Antes de un Sismo

Identifica zonas seguras

Bajo mesas resistentes, junto a columnas, lejos de ventanas

Prepara un kit de emergencia

Agua, alimentos no perecederos, linterna, radio, botiquin

Establece puntos de reunion

Acuerda con tu familia donde encontrarse si se separan

Asegura objetos pesados

Libreros, cuadros, televisores que puedan caer

Durante un Sismo

AGACHATE, CUBRETE, AGARRATE

La tecnica mas importante para sobrevivir

NO uses ascensores

Podrias quedar atrapado

Alejate de ventanas

El vidrio puede romperse y causar heridas

Despues de un Sismo

Revisa tu entorno

Busca danos estructurales, fugas de gas, cables caidos

Cierra llaves de gas

Para prevenir incendios o explosiones

Preparate para replicas

Pueden ser tan fuertes como el sismo principal
